# BUG-12: Footer-ийн «Хуучин хувилбар» линк (/old) 500 Internal Server Error буцаадаг

Орчин:  Уншлагын жагсаалт v2.0, Chromium 153 (Firefox 155-д мөн давтагдсан), Windows 11 Pro, 2026-10-15

Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам
1. Браузераар http://localhost:3000 нээнэ.
2. Хуудасны доод талын «**Хуучин хувилбар**» линк дээр дарна.
3. Терминалд: `curl -i localhost:3000/old`

Хүлээгдэж байсан: «бүх хуудас, линк ажиллана» — хуучин хувилбарын хуудас нээгдэнэ.

Бодит үр дүн:     Хуудсанд зөвхөн «Internal Server Error» текст; curl:
                  `HTTP/1.1 500 Internal Server Error`. `/old?x=1` ч мөн 500.

Ноцтой байдал: Major — үндсэн хуудаснаас шууд хүрэх линк серверийн алдаа өгнө (5xx).
