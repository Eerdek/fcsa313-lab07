# BUG-13: POST /api/books биеэр `null` илгээхэд сервер бүхэлдээ унаж, бүх өгөгдөл алга болдог

Орчин:  Уншлагын жагсаалт v2.0, Chromium 153 (Firefox 155-д мөн давтагдсан), Windows 11 Pro, 2026-10-15

Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам
1. Нэг терминалд `node app.js` ажиллаж байна.
2. Өөр терминалд:
   `curl -i -X POST localhost:3000/api/books -H 'Content-Type: application/json' -d 'null'`
3. Дараа нь: `curl -i localhost:3000/api/books`
4. `node app.js` ажиллаж байсан терминалыг харна.

Хүлээгдэж байсан: `null` нь хүчинтэй JSON боловч ном биш тул **400** алдаа буцааж, сервер үргэлжлэн
                  ажиллана (дүрэм 8 ба эрүүл ухаан: нэг буруу хүсэлт үйлчилгээг зогсоох ёсгүй).

Бодит үр дүн:     2-р алхамд хариу ирэхгүй: `curl: (56) Recv failure: Connection was reset`.
                  3-р алхамд `curl: (7) Failed to connect to localhost:3000`. 4-р алхамд
                  `TypeError: Cannot read properties of null (reading 'title')` гээд процесс
                  дууссан. Санах ойд байсан бүх ном алга (дахин асаахад анхны 3 ном). 25 минут
                  ажиллаж 165 номтой болсон сервер дээр ч яг адил унасан. (`5`, `"text"`,
                  `true` бие унагаадаггүй — 201 буцааж хоосон ном үүсгэнэ, BUG-04.)

Ноцтой байдал: Critical — нэвтрэлтгүй, ганц жижиг хүсэлтээр хэн ч үйлчилгээг зогсоож (DoS), бүх
               хэрэглэгчийн өгөгдлийг устгаж чадна.
