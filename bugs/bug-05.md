# BUG-05: POST /api/books буруу JSON биетэй хүсэлтэд 400 биш «200 OK {"result":"OK"}» буцаадаг

Орчин:  Уншлагын жагсаалт v2.0, Chromium 153 (Firefox 155-д мөн давтагдсан), Windows 11 Pro, 2026-10-15

Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам
1. Терминалд:
   `curl -i -X POST localhost:3000/api/books -d 'буруу оролт'`
2. Терминалд (хаалтгүй, эвдэрхий JSON):
   `curl -i -X POST localhost:3000/api/books -H 'Content-Type: application/json' -d '{"title": "X",'`
3. Терминалд: `curl -i localhost:3000/api/books`

Хүлээгдэж байсан: «API: буруу JSON биетэй POST хүсэлтэд 400 алдаа буцаана».

Бодит үр дүн:     1, 2-р алхам хоёулаа `HTTP/1.1 200 OK` ба `{"result":"OK"}`. 3-р алхамд жагсаалт
                  3 номтой хэвээр — ном нэмэгдээгүй атлаа сервер "OK" гэж худал хариулдаг.
                  `{`, `abc`, `{'title':'a'}`, `{"title":"a",}`, `<xml/>`, form-urlencoded бие —
                  бүгд мөн 200 OK.

Ноцтой байдал: Major — API-ийн гэрээг зөрчиж, клиент алдааг огт мэдэж чадахгүй (өгөгдөл алдагдсан
               ч амжилттай гэж ойлгоно); CI/интеграцийн тест ч баригдахгүй.
